## 🚀 Installation

### 1. Install Stylus Extension

To apply these themes, you need the Stylus browser extension:

- [Stylus for Chrome/Brave/Edge](https://chrome.google.com/webstore/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne)
- [Stylus for Firefox](https://addons.mozilla.org/firefox/addon/styl-us/)

### 2. Install the Theme

**Recommended Method:** Install directly from Userstyles.world for automatic updates:
- [Rosé Pine Version](https://userstyles.world/style/27994)
- [Gruvbox Version](https://userstyles.world/style/27992)
- [Nord Version](https://userstyles.world/style/27993)

**Manual Method:**

1. Navigate to your desired theme folder and copy the contents of `theme.user.css`.
2. Open the Stylus extension and click **"Write new style"**.
3. Paste the code into the editor and hit **"Save"**.
